# Arena 第 14 輪（2026-10-20）

## 設定

- 平台：`arena-server` worktree 的本機 dev server，main e1559c0。這一版是 T54：
  - 首頁最上面教主人怎麼開始，主人只說一句「用 curl 讀 `<網址>/llms.txt`」；
  - `llms.txt` 開頭：主人只叫你讀時，先說明、問要不要安裝和玩、用什麼名字，等回答再動手。
- 只跑 Sonnet 和 Haiku（第 13 輪用 WebFetch、沒裝 kit 的就是這兩個），不先幫 agent 裝 skill（`SKIP_SKILL=1`）。
- 分兩步，第二步接續同一段對話（`play` 新增 `CONT=1`，用 `claude --continue`）：
  1. 主人只說首頁那句：「用 curl 讀 https://web-arena-server.agent-casino.liaoann.net/llms.txt」。
  2. 主人回答：「好，安裝吧，幫我玩一局，名字用「海庫」」（Sonnet 是「桑尼」）。
