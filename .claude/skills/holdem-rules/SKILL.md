# 德州撲克單挑規則

## 牌的寫法
- 點數：`2 3 4 5 6 7 8 9 T J Q K A`；花色：`s h d c`。一張牌寫成兩個字元，例如 `Ah`、`Td`、`2c`。

## 房間預設設定（開房時都能改）

| 設定 | 預設 | 允許範圍 |
| --- | --- | --- |
| 座位數 | 2 | 只能 2 |
| 盲注 | 小盲 1 / 大盲 2 | 固定 |
| 起始籌碼 | 40（= 20 個大盲） | 10–2000 |
| 手數 | 10 | 1–200 |
| 每步時限 | 60 秒 | 5–300 秒 |
| 超時動作 | 能過牌就過牌，否則棄牌 | 固定 |
| 等人解散 | 房間 5 分鐘沒湊滿就解散 | 固定 |

測試時常用：1 手、每步 10 秒。

## 一手牌的流程
1. **莊家（button）= 小盲**。第 1 手由座位 0 當莊家，之後每手交換。
2. 自動下盲注：莊家下小盲，對手下大盲。籌碼不夠就全下能下的。
3. 每人發 2 張底牌。
4. **翻牌前（preflop）由莊家（小盲）先行動**；翻牌後（flop、turn、river）**由大盲先行動**。
5. 發公牌：flop 3 張、turn 1 張、river 1 張。
6. 一輪下注結束的條件：兩人都行動過，且下注額相同（或有人全下）。
7. 有人棄牌：另一人拿走底池，這手結束。
8. 兩人都全下：直接把剩下的公牌發完，攤牌。
9. **攤牌**：7 張選最好的 5 張比大小；平手就平分，除不盡的那 1 個籌碼給非莊家。

## 動作（`type`）
| 動作 | 什麼時候合法 | `amount` |
| --- | --- | --- |
| `fold` | 輪到你時永遠合法（就算可以過牌） | 不帶 |
| `check` | 這輪你不用補錢時 | 不帶 |
| `call` | 對手下注比你多時 | 不帶（平台回傳要補多少） |
| `raise` | 你還有籌碼、且對手沒全下時；也用來表示「第一個下注」 | **加注到**這一輪的總額（不是再多加多少） |

- **最小加注**：加注到的總額 ≥ 目前最高下注 + 上一次加注的幅度（這輪還沒人加注時，幅度 = 大盲 2）。
- **最大加注**：全下（你這輪已下的 + 手上剩的）。
- 籌碼不夠最小加注時，可以全下；**不足額的全下不會重新開放對手加注**，對手只能跟或棄。
- **沒人跟的多出來的下注要退回**給下注的人。

## 比牌大小（大到小）
同花順 > 四條 > 葫蘆 > 同花 > 順子 > 三條 > 兩對 > 一對 > 高牌。`A2345` 是最小的順子（也算同花順）。同牌型比 kicker。用公開的牌型對照資料做測試的標準答案。

## 整場（match）結束
- 打滿設定的手數，或有人籌碼歸零。
- 籌碼多的贏；一樣多算平手。
- 主動離開（`POST /leave`）算輸。


## 種子與洗牌
- 每場有一個 32 位元無號整數種子（正式環境隨機產生；測試房可用 `test.seed` 指定）。
- PRNG 用 **mulberry32**。第 n 手（從 1 開始）的牌組 = 用 `mulberry32((seed + n * 0x9E3779B9) >>> 0)` 對標準 52 張（順序：點數 2→A，每個點數內 s、h、d、c）做 Fisher–Yates 洗牌。
- mulberry32 用 bryc 公開的標準實作，每次呼叫輸出 [0, 1) 的浮點數：
  ```js
  function mulberry32(a) {
    return () => {
      a = (a + 0x6D2B79F5) | 0;
      let t = Math.imul(a ^ (a >>> 15), 1 | a);
      t = (t + Math.imul(t ^ (t >>> 7), 61 | t)) ^ t;
      return ((t ^ (t >>> 14)) >>> 0) / 4294967296;
    };
  }
  ```
- Fisher–Yates 用 Durstenfeld 版，從尾端開始：`for i = 51 down to 1`，`j = Math.floor(rng() * (i + 1))`，交換 `deck[i]` 和 `deck[j]`。每次交換正好用掉一個亂數，不做 rejection sampling。
- 洗完的 `deck[0]` 是第一張發出的牌。發牌順序：座位 0 第 1 張（`deck[0]`）、座位 1 第 1 張（`deck[1]`）、座位 0 第 2 張（`deck[2]`）、座位 1 第 2 張（`deck[3]`），接著 flop 3 張（`deck[4..6]`）、turn 1 張（`deck[7]`）、river 1 張（`deck[8]`），不燒牌。
- 這些細節決定了「同一個種子永遠同一副牌」，改了舊的對局就無法重播。測試要固定幾組「種子 + 手數 → 前 9 張牌」的標準答案。


## 邊界情況
- **盲注不夠**：有多少下多少，視為全下。
- **小盲因下盲注全下**：大盲不用再行動，多出來的退回後直接發完公牌。
- **大盲因下盲注全下**：小盲只能跟或棄（不能加注）。
- **大盲的 option**：翻牌前小盲只跟注時，大盲還可以過牌或加注。
- **跟注超過自己籌碼**：`call` 的 `amount` 顯示實際能補的數字（全下）。
- **籌碼不夠最小加注**：只要籌碼多於跟注額，`raise` 的 `min` = `max` = 全下的總額。
- **對手已經全下**：只能跟或棄，不提供 `raise`。
- **不足額全下**：不會讓已經行動過的人重新獲得加注權（單挑時就是對手只能跟或棄）。
- **一輪結束**：還能行動的人在這一輪都行動過，且雙方這輪下注額相同（或有人全下且已被跟或不能再跟）。
- `call` 的 `amount` 是**要再補多少**；`raise` 的 `amount` 是**加注到的總額**。這是常見陷阱，skill.md 也要寫清楚。
